ROS Command v0.5.0
==================
Welcome to ROS Command, a lightweight
command-line kernel written in assembly.

Developer : XR Stu
Website   : https://xrst.uk

This disk is a virtual hard disk with a
FAT16 partition, booted via MBR + VBR.
Try these commands:
  help            - list all commands
  dir             - list files on this disk
  doc README.TXT  - show this file again
