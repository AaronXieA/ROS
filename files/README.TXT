ROS Command Alpha v0.14.0
=========================
Welcome to ROS Command, a small command
line operating system: a 32-bit protected
mode kernel written in C, booted by our
own MBR + FAT16 VBR, with the xsh shell.

Try these commands:
  help             - list all commands
  dir              - list files on this disk
  doc README.TXT   - show this file again
  echo hi > A.TXT  - write a file
  dir | grep TXT   - pipe output
  jvm HELLO.CLS    - run a Java 8 class file
  ping 10.0.2.2    - ICMP echo test
  vm               - paging information
  ps               - list processes
  pck search       - list installable packages

pck install doce adds DocEditor, a
full-screen text editor: doce A.TXT.
